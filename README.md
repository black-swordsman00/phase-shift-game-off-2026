# Phase Shift

A 2D top-down stealth/puzzle game built in Python with Pygame for **GitHub Game Off 2026** (Theme: **SHIFT**).

## Controls
- **WASD / Arrow Keys**: Move
- **SPACE / SHIFT**: Shift between Light and Dark dimensions
- **R**: Restart current level

## How to Run
```bash
pip install -r requirements.txt
python main.py
